# План тестирования

Объект: PharmacySystem.

Область: добавление, редактирование, поиск, продажа лекарств, контроль срока годности, контроль остатка, сохранение данных и операций в SQLite.

Не входит в область: интеграция с банковским терминалом, реальная печать чеков, работа с аппаратным сканером штрихкодов.

Критерий начала: сборка проекта восстановлена без ошибок, тестовая БД создаётся.
Критерий завершения: все Must-требования имеют тесты; критические дефекты отсутствуют; полный набор автотестов проходит.
